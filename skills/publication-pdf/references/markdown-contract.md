# 출판용 Markdown 작성 계약

이 계약은 “아무 Markdown이나 변환”하기 위한 규칙이 아니라, Typst가 일관된 출판물 수준의 PDF를 만들 수 있도록 원고 구조를 명확히 하는 최소 subset이다.

## Metadata

```yaml
---
title: 월간 운영 보고서
subtitle: 2026년 7월
author: 운영팀
date: 2026-07-14
lang: ko
---
```

- `title`은 필수다.
- 제목을 본문에서 다시 `#`로 반복하지 않는다.
- `fontsize`, `margin`, 색상 같은 조판 값은 원고보다 템플릿에서 관리한다.

## 제목과 문단

```markdown
# 요약

첫 문단입니다. 문단 사이에는 빈 줄을 둡니다.

두 번째 문단입니다.

## 주요 결과

본문입니다.
```

- `#` → `##` → `###` 순서를 지킨다.
- 한 문서에 `#` 제목을 지나치게 많이 만들지 않는다.
- 제목 대신 `**굵은 문장**`을 사용하지 않는다.
- 수동 줄바꿈보다 문단을 사용한다.

## 목록

```markdown
- 첫 번째 항목
- 두 번째 항목

1. 먼저 확인한다.
2. 결과를 검증한다.
```

목록 항목 안에 긴 표나 여러 코드 블록을 중첩하지 않는다.

## 표

```markdown
| 항목 | 현재 | 목표 | 판단 |
|---|---:|---:|---|
| 처리 시간 | 12분 | 8분 | 개선 필요 |
```

- 숫자는 오른쪽 정렬한다.
- A4 세로에서는 5~6열을 기본 상한으로 본다.
- 셀 안의 긴 문단, 코드, 다중 목록을 피한다.
- 넓은 표는 분리·행/열 전치·가로 페이지·부록 이동 중 하나를 선택한다.

## 인용과 강조

```markdown
> 핵심 판단: 페이지 수를 억지로 줄이는 것보다 읽기 쉬운 수직 리듬이 우선이다.

중요한 용어는 **굵게**, 가벼운 강조는 *기울임*으로 표시한다.
```

강조를 색상이나 직접 HTML로 표현하지 않는다. 스타일은 템플릿이 담당한다.

## 코드

````markdown
```ts
export function render(): void {
  console.log('ready');
}
```
````

- 언어 이름을 넣는다.
- 한 줄이 지나치게 길면 원본 코드에서 적절히 줄바꿈한다.
- 코드가 한 페이지를 넘으면 일부를 발췌하거나 부록으로 옮긴다.

## Mermaid

````markdown
```{.mermaid caption="출판 흐름" alt="Markdown을 Typst PDF로 변환하고 검증하는 흐름"}
flowchart LR
  A[Markdown] --> B[Pandoc]
  B --> C[Typst]
  C --> D[PDF 검수]
```
````

- `.mermaid` class를 사용한다.
- `caption`은 그림 아래에 표시할 설명이다.
- `alt`는 그림을 보지 못하는 독자도 의미를 이해하도록 작성한다.
- 노드 수가 너무 많으면 다이어그램을 분리한다.

## 수식과 각주

```markdown
인라인 수식은 $E = mc^2$처럼 쓴다.

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

각주는 문장 끝에 둔다.[^source]

```

## 이미지

```markdown
![처리 단계별 결과를 비교한 막대그래프](assets/result-chart.png){fig-cap="처리 단계 비교"}
```

- 프로젝트 내부 상대 경로를 사용한다.
- 원격 URL에 의존하지 않는다.
- 작은 스크린샷을 무리하게 확대하지 않는다.

## 페이지 분할

정말 필요한 경우에만 쓴다.

````markdown
```{=typst}
#pagebreak()
```
````

페이지를 맞추기 위해 빈 줄을 반복하거나 공백 문자를 넣지 않는다.

## 지원하지 않는 입력

- 임의 HTML/CSS 혼합
- 실행 중 외부 CDN이나 font download가 필요한 문서
- 표 안의 복잡한 block content
- 신뢰할 수 없는 raw Typst code
- 슬라이드형 자유 배치
- 원고 의미를 숨기는 과도한 macro
