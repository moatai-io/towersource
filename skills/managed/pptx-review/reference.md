# pptx-review — 평가 기준 (한국식 컨설팅 톤)

10 dimension × 1-5점 채점. 각 dimension 의 정의 + 예시 + 1점/5점 기준.

---

## D1. 텍스트 Overflow (가장 자주 깨지는 것)

**1점**: 글자가 박스 밖으로 잘림 / 다른 요소와 겹침
**3점**: 박스 안에 들어가지만 너무 빽빽 (margin 부족)
**5점**: 박스 안에 여유롭게, 줄바꿈 자연스러움

**한국어 특징**: 한글은 영어보다 dense 함. 영문 80자 들어가는 폭에 한글은 50자 정도.

자동 진단 가능: bullet/title/takeaway/insight 길이 측정.

---

## D2. 헤더·푸터 Chrome 정합성

**1점**: chrome 누락 또는 위치 깨짐
**3점**: chrome 있지만 회사명·페이지·출처 일관성 부분 깨짐
**5점**: 모든 콘텐츠 슬라이드에 회사명·프로젝트·페이지·출처 일관

체크 포인트:
- 모든 content 슬라이드에 page 번호 (NN / TT)
- meta.company / project_short 노출
- source 또는 source_default 노출
- confidential 명시 시 우상단

---

## D3. Takeaway 강조 효과

**1점**: takeaway 없음 / 본문과 구분 안 됨
**3점**: takeaway 있지만 너무 길거나 평이함
**5점**: 한 줄 결론, ▶ 마커 + 오렌지 강조, "so what" 분명

좋은 takeaway 패턴:
- 짧다 (40-60자)
- 결론적이다 ("X = Y" / "A → B")
- 본문이 takeaway 를 뒷받침한다

---

## D4. Insight 콜아웃 가독성

**1점**: 콜아웃 없음 또는 본문과 묻힘
**3점**: 있지만 위치/크기 어색
**5점**: 하단 회색 panel + 좌측 accent + "결론" 라벨 명확

---

## D5. 색상 일관성

**1점**: 다양한 색 / 톤 깨짐 / 한 슬라이드에 4+ 색
**3점**: 톤 OK 지만 강조 색이 너무 많거나 약함
**5점**: 네이비 + 오렌지 (+ 패널 그레이) 만으로 위계 명확

한국 컨설팅 표준: 강조 색은 1개 (오렌지). 네이비는 정보, 오렌지는 강조, 그레이는 배경.

---

## D6. 한글/영문 폰트 균형

**1점**: 한글이 □ 박스로 깨짐 / 폰트 다양함
**3점**: 한 폰트로 통일되어 있지만 한영 mix 가 어색 (영문이 너무 두꺼움 등)
**5점**: Noto Sans CJK KR / Pretendard 단일 폰트, 한영 혼용 자연스러움

자동 진단 어려움: vision 으로만 잡힘 (□ 박스 발견).

---

## D7. 정보 밀도

**1점**: 슬라이드의 60%+ 가 빈 영역 (스파스) 또는 빈 카드
**3점**: 균형은 OK 지만 한 영역만 빽빽
**5점**: 콘텐츠가 슬라이드 영역에 자연스럽게 분산 / 빈 영역 < 25%

한국 컨설팅 톤: dense 한 정보 밀도 선호. 미국식 "한 슬라이드 한 메시지" 보다 정보 많음.
하지만 너무 빽빽하면 가독성 떨어짐 — 균형이 핵심.

---

## D8. 한국 컨설팅 톤 적합성

**1점**: 미국식 pitch deck / 학술 발표 톤 — B2B 한국에서 가벼워 보임
**3점**: 일반적 비즈니스 톤 — 무난하지만 임팩트 약함
**5점**: 한투/PwC/베이AI 같은 톤 — 헤더+takeaway+insight+footer 가 강한 위계

체크:
- 헤더 바 / 챕터 표시
- ▶ takeaway / 결론 콜아웃
- 출처 명시 / 비밀등급
- 챕터 진행 트래커
- 정중한 어조 (불릿 본문)

---

## D9. 출처·페이지·비밀등급 표기

**1점**: 출처 없음, 페이지 없음
**3점**: 페이지만 있고 출처는 누락
**5점**: 모든 데이터 슬라이드에 출처 / 모든 페이지에 NN/TT / 외부 자료에 비밀등급

---

## D10. 챕터 트래커·목차 정합성

**1점**: 목차 없음 / 챕터 번호 불일치
**3점**: 목차 있지만 페이지 번호 빈칸 / chapter_idx 맞지 않음
**5점**: 목차 + section 진행 트래커 + 헤더 챕터 표시 모두 일관

---

## 종합 점수 가이드

- **40-50점** (★★★★★): 발표 준비 완료. 미세 조정만.
- **30-39점** (★★★★): 좋다. 1-3개 high 이슈 fix 후 OK.
- **20-29점** (★★★): 무난. 5-7개 medium 이슈 정돈 권장.
- **10-19점** (★★): 톤 부족. 한국식 chrome / takeaway / insight 도입 필요.
- **< 10점** (★): 처음부터 다시.

---

## 자주 발견되는 이슈 패턴 (codify)

### Pattern 1 — KPI value 줄바꿈
**증상**: "약 5권" 이 "약 5\n권" 으로 두 줄
**원인**: KPI 카드 너비 < 64pt 한글 4자
**Fix**: yaml 에서 value 더 짧게 ("5권") 또는 폰트 자동 축소 사용

### Pattern 2 — Bullet 마커 안 보임
**증상**: ▶ 또는 특수 글자가 빈칸으로 렌더
**원인**: PPTX native bullet 의 buFont (Arial) 에 해당 글자 없음
**Fix**: theme.bullet_char 를 ● 또는 • 로

### Pattern 3 — Takeaway 두 줄
**증상**: takeaway 가 한 줄 바 안에 두 줄로 들어감
**원인**: 80자 초과 (한글 ~40자 초과)
**Fix**: takeaway 단축. "X 의 근본 원인 = Y" 형식 권장

### Pattern 4 — Cover 슬라이드 줄바꿈
**증상**: 표지 또는 cover_short 헤드라인 두 줄
**원인**: 한글 22자 이상 32pt 에서 한 줄 안 됨
**Fix**: 헤드라인 짧게 또는 폰트 축소

### Pattern 5 — Section 트래커 missing
**증상**: section 페이지인데 하단 트래커 없음
**원인**: meta.chapters 없거나 chapter_idx 미지정
**Fix**: yaml 에 둘 다 추가

### Pattern 6 — Source 누락
**증상**: 데이터 인용한 슬라이드에 출처 없음
**원인**: meta.source_default 만 있고 슬라이드별 source override 없음
**Fix**: 슬라이드별 source 추가

## Vision 평가 시 주의사항

1. **한 번에 5장씩** — 너무 많이 한 번에 읽으면 평가 일관성 떨어짐
2. **앵커 슬라이드** — 제일 잘 된 슬라이드 1장을 5점 기준으로 잡고 나머지 평가
3. **컨텍스트 제공** — meta (회사·프로젝트) 를 알고 평가해야 톤 적합도 판단 가능
4. **bias 주의** — Claude 자기 자신이 만든 결과물 평가 시 점수 후한 경향. 박하게.
