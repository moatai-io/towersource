# Project: Tower OSS

This is the public/open-source export of Tower. Keep public documentation generic:

- Do not add customer names, private domains, public IPs, SSH targets, credentials, or internal runbooks.
- Use `.env.example` for configuration shape only; never commit real values.
- Put deployment instructions in generic self-hosting terms unless they are explicitly safe for public users.
- Operator-only fleet/customer/backup/router procedures belong in the private operations repository, not here.
