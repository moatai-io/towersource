# Internal Channels retirement and current work paths

The internal Channels UI is retired. This address preserves earlier help links as a transition page. Do not follow previous channel creation, `@ai`, `@task`, or thread execution instructions as current usage. The previous text remains in Git history.

## Find the relevant current guide

| Goal | Current guide |
|---|---|
| Ask AI to analyze, write, or edit | [Sessions](./02-sessions.md) |
| Delegate substantial separable work | [Support AI](./10-support-ai.md) |
| Inspect and deliver artifacts | [Files](./04-files.md) |
| Review progress and related conversations | [Work and Automations](./05-work-and-automations.md) |
| Check notifications, access, and services | [Settings and Connections](./07-settings-permissions-connections.md) |

These paths do not replace every earlier team-chat capability. Internal Channels retirement does not imply deletion of historical data or retirement of all external messenger integrations. If your installation exposes other collaboration or integration surfaces, check their actual behavior and access rules.

Sharing a Session or file link does not automatically grant access. Confirm the recipient and the content to deliver.
