# Getting started

Tower is a self-hosted workspace for working with AI teammates, files, tools, and automations. Available models and tools depend on your server and the selected Agent; Tower is not limited to one model provider.

## Your first task

1. Choose an AI teammate whose role matches the work, or open an accessible Project.
2. Start a Session and describe the outcome, audience, source material, and limits.
3. Review questions and approval requests. A permission to inspect does not automatically authorize changes, publishing, or deployment.
4. Inspect the result in the conversation and the right-side Viewer. Keep important outputs in the Project.
5. Return to the Session for follow-up work, or use Automations when you need recurring execution.

## Understand the workspace

| Area | What it is for |
|---|---|
| AI teammates | Find a responsible Agent and enter its workspace |
| Sessions | Requests, tool execution, questions, and follow-up conversation |
| Files and Viewer | Inspect source material and generated artifacts |
| Work | Review work records and related conversations |
| Automations | Configure and monitor recurring or scheduled execution |
| Settings and Connections | Manage available personal options and authorized service access |

Navigation varies with screen size, permissions, and server configuration. A feature described here may require an enabled service or Connection.

## Projects and Sessions

A Project owns the file and access boundary. A Session records a conversation within that context. Starting another Session does not create an isolated copy of the Project files. Sessions and support AI working in the same Project can affect the same files.

Do not assume a Session is visible only to you: access depends on its ownership, sharing, and applicable Project or audience rules. A link does not grant access by itself.

## Attach and preserve material

You can attach files and screenshots to a request. A conversation attachment is temporary material; asking AI to read it does not automatically ask it to save the original permanently. Explicitly request storage when you want to keep it.

For ongoing work, follow the Project's existing folder rules. If it uses `sources/`, `work/`, `final/`, and `records/`, keep source material, drafts, final outputs, and records in their respective locations.

## Delegate clearly

Include the desired result, readers, constraints, and evidence of completion. For substantial separable work, ask the main AI to coordinate support AI; it remains responsible for integrating and verifying their results. See [Support AI](./10-support-ai.md).
