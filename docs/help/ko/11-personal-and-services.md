# 개인 업무·비서실·AI 서비스

개인 자료, AI의 업무 기록, 예약 실행, 외부 독자용 서비스는 목적과 권한이 다릅니다. 실제 메뉴와 제공 범위는 계정 역할·서버 설정·설치 버전에 따라 달라집니다.

## 개인 공간과 내 할 일

개인 공간은 본인 자료를 보관하는 위치입니다. 프로젝트 파일과는 별도이며, 자료를 다른 프로젝트로 전달하려면 목적지와 접근 권한을 확인해야 합니다.

**내 할 일**은 사용자가 직접 관리하는 개인 체크리스트입니다. 화면에서 항목을 추가하고 완료 여부를 바꿀 수 있습니다. AI에게 개인 할 일 등록을 요청할 때는 “내 할 일에 추가해줘”라고 명확히 말하세요.

| 구분 | 다루는 것 |
|---|---|
| 내 할 일 | 사용자의 개인 체크리스트 |
| 진행 단계 | 현재 AI 실행이 수행할 단계와 상태 |
| 내 작업 | 장기 업무 기록과 관련 실행·대화 |
| 자동화 | 정해진 시점·주기로 실행할 AI 작업 |

“할 일”이라는 말만으로 반복 예약까지 생성하려는 의도가 전달되지는 않습니다. 예약이 필요하면 시각·주기·시간대·결과 위치를 함께 정합니다.

## 비서실

비서실은 진행 중인 업무에서 필요한 확인과 다음 작업의 제안을 모아 보는 개인 화면입니다. 계정별로 활성화 여부를 선택하고, 기존 제안의 근거가 된 세션으로 이동할 수 있습니다.

비서실의 제안을 읽거나 활성화하는 것이 외부 발송·업무 실행·승인을 자동으로 허용하지는 않습니다. 제안의 근거와 오래된 상태 여부를 확인하고 실행할 일을 판단하세요. 제안 생성 경로와 설정이 준비되지 않은 설치에서는 제안이 없을 수 있습니다.

## AI 팀 관제실과 대시보드

AI 팀 화면에 관제실이 제공되는 경우, 접근 가능한 프로젝트에서 **명시적으로 등록한** 대시보드를 모아 볼 수 있습니다. 계산기 파일을 만들었다는 이유만으로 자동 등록되지는 않습니다.

시각적인 팀 편성은 다른 프로젝트 파일 접근 권한을 주지 않습니다. 일부 프로젝트를 읽지 못한 경우 부분 로드 경고와 데이터 시점을 확인하세요. 지원 지표와 실제 데이터 갱신 경로가 있는지도 별도로 확인해야 합니다.

## AI 서비스

AI 서비스는 외부 이용자에게 제공할 제한된 대화 서비스와 그 채널을 관리하는 기능입니다. 내부 AI 팀원의 모든 파일·도구·연결을 외부 사용자에게 그대로 공개하는 기능은 아닙니다.

관리 화면이 제공되고 필요한 권한이 있을 때, 서비스 지침·허용 기능·지식 자료·채널 접근 조건을 확인하고 운영합니다. 초안 생성, 활성화, 채널 공개, 접근 조건과 사용량 제한은 서로 다른 상태와 설정입니다.

공개 전에는 다음을 확인하세요.

- 외부 독자와 서비스 목적이 분명한가요?
- 허용 도구와 지식 자료에 비공개 내용이 섞이지 않았나요?
- 채널의 접근 정책과 사용량 제한이 적절한가요?
- 실제 공개 상태와 테스트 대화 결과를 확인했나요?

관리 권한과 서버 설정이 필요하므로 모든 사용자가 생성·공개할 수 있다고 가정하지 마세요. HTML 결과물을 게시하는 것과 AI 대화 서비스를 운영하는 것은 별개입니다.

## 음성 입력과 답변 읽기

입력창의 음성 입력은 말한 내용을 메시지 초안으로 옮기는 기능입니다. 답변 읽기·답변 알림음은 출력 기능이며 각각 설정과 제공 조건이 다를 수 있습니다. 마이크 권한과 연결 상태를 확인하고, 음성 초안은 전송 전에 검토하세요.

개발·관리용 Voice Lab 화면의 존재가 일반 사용자의 실시간 음성 대화 제공을 보장하지는 않습니다.
