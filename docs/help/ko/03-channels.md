# 내부 채널 종료와 현재 작업 경로

내부 채널 UI는 종료되었습니다. 이 주소는 이전 도움말 링크를 유지하는 전환 페이지입니다. 채널 생성, `@ai`, `@task`, 스레드 실행 절차를 현재 사용법으로 따라 하지 마세요. 이전 설명은 Git 기록에서 확인할 수 있습니다.

## 지금 하려는 일에 맞는 경로

| 하려는 일 | 현재 안내 |
|---|---|
| AI에게 분석·작성·수정 요청 | [세션](./02-sessions.md) |
| 큰 일을 나누어 맡기기 | [지원 AI](./10-support-ai.md) |
| 결과 파일 확인·전달 | [파일](./04-files.md) |
| 진행 상황과 관련 대화 확인 | [내 작업과 자동화](./05-tasks.md) |
| 알림과 접근·연결 설정 확인 | [설정·권한·Connection](./07-settings.md) |

이 경로들이 과거 채널의 모든 팀 채팅 기능을 그대로 대체한다는 뜻은 아닙니다. 내부 채널 종료가 기존 데이터 삭제나 모든 외부 메신저 연동의 종료를 뜻하지도 않습니다. 별도 협업·연동 화면이 제공된다면 그 화면의 실제 기능과 접근 규칙을 확인하세요.

세션이나 파일의 링크를 공유해도 상대에게 권한이 자동으로 생기지 않습니다. 접근 가능한 대상과 전달할 내용을 먼저 확인하십시오.
