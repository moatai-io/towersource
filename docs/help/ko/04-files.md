# 파일 — 산출물과 전달

자료를 AI에게 보여주는 것, 프로젝트에 보관하는 것, 다른 사람에게 전달하는 것은 서로 다른 작업입니다. 원하는 범위를 명시하면 불필요한 복사와 외부 공유를 줄일 수 있습니다.

## 프로젝트 파일과 Viewer

프로젝트의 Files에서 파일과 폴더를 탐색합니다. 파일을 선택하면 오른쪽 Viewer에서 지원되는 형식의 미리보기나 편집 화면을 사용할 수 있습니다. 파일의 종류와 권한에 따라 가능한 작업이 다릅니다.

파일·폴더 만들기, 이름 변경, 경로 복사, 다운로드 등의 작업은 해당 화면의 메뉴에서 확인합니다. 삭제·덮어쓰기·여러 파일 변경은 대상을 먼저 확인하세요. 읽기 전용 권한에서는 수정할 수 없습니다.

AI가 파일을 만들었다면 완료 응답에서 **파일명과 실제 경로**를 확인합니다. Viewer 표시 요청, 파일 저장, 다운로드·전달은 각각 별개입니다.

## 자료를 어디에 둘까요?

프로젝트에 이미 있는 구조를 우선합니다. `sources/`, `work/`, `final/`, `records/`를 사용하는 프로젝트라면 원본, 초안, 최종본, 기록을 나누어 둡니다. 새 폴더 체계를 매번 만들 필요는 없습니다.

| 위치 | 용도와 주의점 |
|---|---|
| 대화 첨부 | 이번 대화에서 사용하는 임시 자료. 영구 보관 여부를 별도로 결정합니다. |
| 프로젝트 파일 | 해당 프로젝트의 접근·쓰기 권한을 따르는 자료와 산출물 |
| 개인 공간 | 본인 보관용 사본. 프로젝트와 같은 저장 위치가 아닙니다. |
| 다른 AI 팀원의 프로젝트 | 접근 가능한 목적지에 명시적으로 전달하는 사본 |
| 게시된 사이트 | 프로젝트 파일 열람과 다른 별도 게시·접근 정책을 따릅니다. |

## 첨부와 원본 보관

파일·이미지를 대화에 첨부해 분석을 요청할 수 있습니다. PDF·Office 문서 등의 지원 범위는 설치된 도구와 스킬에 따라 달라집니다.

“읽고 요약해줘”라는 요청만으로 첨부 원본을 프로젝트에 영구 저장하지 않습니다. 원본도 보관하려면 “이 프로젝트에 원본을 저장해줘”라고 말하세요. 변환한 산출물과 첨부 원본의 보관은 구분합니다.

## 기존 파일 수정하기

> 이 프로젝트의 `final/report.md`에서 결론만 수정해줘. 다른 절은 보존하고 같은 파일을 갱신해줘.

수정 대상과 보존할 범위를 지정하세요. 같은 프로젝트의 여러 세션·지원 AI가 같은 파일을 사용할 수 있습니다. 동시에 일할 때는 파일과 수정 구간의 소유권을 나누고 최신 내용을 확인합니다.

## 파일 전달하기

AI에게 기존 프로젝트 파일을 현재 대화의 첨부로 전달하거나, 개인 공간 또는 접근 가능한 다른 AI 팀원의 프로젝트로 복사해 달라고 요청할 수 있습니다. 다른 저장 위치로 전달할 때는 목적지를 정확히 지정하고 확인합니다.

> 완성된 PDF를 이 대화에 첨부해줘.

> 이 최종 보고서 한 개를 지정한 AI 팀원의 프로젝트에 복사해줘. 원본은 그대로 두고 기존 파일을 덮어쓰지 마.

전달은 기본적으로 사본을 만드는 작업이며 원본을 옮기거나 삭제하는 작업이 아닙니다. 폴더 전달에는 파일 수·심볼릭 링크 등 제한이 있을 수 있고 기존 파일은 덮어쓰지 않습니다. 지원하지 않는 목적지 조합은 거절될 수 있습니다.

드래그·메뉴로 전달하는 화면이 제공되면 해당 경로를 사용할 수 있습니다. 파일 트리 안의 이동·이름 변경과 저장소 사이의 전달은 구분하세요.

## 공유와 게시

파일 경로를 알려주는 것만으로 상대에게 접근 권한이 생기지 않습니다. 외부 독자에게 웹페이지를 보여주려면 별도 게시가 필요합니다.

게시 전에 대상 독자, 포함할 내용, 접근 범위를 확인합니다. **비공개 목록(unlisted) 링크는 로그인 기반 비밀 보관을 뜻하지 않습니다.** 링크가 전달되면 내용을 볼 수 있으므로 비밀·Credential·비공개 자료를 포함하지 마세요. 자세한 내용은 [시각화와 산출물](./06-visual-blocks.md)을 참고하십시오.

## 최종 확인

- 요청한 파일이 실제로 저장되었는지 경로로 확인합니다.
- 미리보기와 다운로드한 최종본의 표·글꼴·페이지를 확인합니다.
- 검사 완료와 실제 게시·전달 완료를 구분합니다.
- 공유할 내용과 원본 자료의 보관 범위를 따로 판단합니다.
