# 처음 시작하기

Tower는 AI 팀원과 대화하고, 파일을 만들고, 도구를 실행하고, 반복 업무를 운영하는 셀프호스트형 업무 공간입니다. 사용할 수 있는 모델과 도구는 서버 설정과 선택한 Agent에 따라 달라집니다.

> **AI 팀원 선택 → 세션에서 요청 → 결과와 근거 확인 → 필요한 곳에 저장·전달**

## 1. 담당 AI 팀원과 프로젝트 확인하기

업무에 맞는 AI 팀원을 찾고 작업공간에 들어갑니다. 프로젝트는 관련 파일·세션·지침을 모으고 접근 권한을 정하는 경계입니다. AI 팀원에게 접근할 수 있다고 해서 다른 프로젝트의 파일이나 연결까지 사용할 수 있는 것은 아닙니다.

프로젝트에 `AGENTS.md`와 폴더 규칙이 있으면 그 기준을 따릅니다.

| 위치 예시 | 넣는 것 |
|---|---|
| `sources/` | 보관하기로 한 원본 자료 |
| `work/` | 초안과 중간 분석 |
| `final/` | 공유 가능한 최종본 |
| `records/` | 실행 기록과 검증 근거 |

모든 프로젝트가 같은 폴더 구조를 쓰는 것은 아닙니다.

## 2. 세션에서 첫 요청하기

선택한 AI 팀원이나 프로젝트에서 새 세션을 열고 원하는 결과를 설명합니다. 목적, 독자, 자료, 결과 형식, 허용 범위를 알려주면 좋습니다.

> 이 매출 Excel을 임원회의용으로 분석해줘. 변화가 큰 항목 세 개와 추가 확인이 필요한 점을 정리해서 이 프로젝트에 저장해줘. 외부 전송은 하지 마.

세션은 주제별로 나누면 다시 찾기 쉽습니다. 다만 같은 프로젝트의 여러 세션이 같은 파일을 사용할 수 있으므로, 새 세션이 별도 파일 사본을 만드는 것은 아닙니다.

세션을 항상 본인만 볼 수 있다고 가정하지 마세요. 소유·공유·프로젝트와 대상 독자에 따른 접근 규칙이 적용되며, 링크만 전달해도 상대의 권한이 생기는 것은 아닙니다.

## 3. 자료 첨부하기

파일과 스크린샷을 입력창에 첨부하거나 프로젝트 파일의 경로를 알려줄 수 있습니다.

- **대화 첨부:** 이번 대화에서 분석할 임시 자료입니다. 읽어 달라는 요청이 원본의 영구 저장을 뜻하지 않습니다.
- **프로젝트 파일:** 나중에도 사용할 자료입니다. 첨부를 보관하려면 “이 프로젝트에 원본도 저장해줘”라고 명시합니다.

## 4. 진행과 결과 확인하기

AI는 필요한 경우 선택형 질문이나 승인 요청을 보여줍니다. 분석 요청은 변경·게시·외부 발송까지 자동으로 허용하지 않습니다.

결과는 대화와 오른쪽 Viewer에서 확인합니다. 중요한 산출물은 프로젝트 안에 저장하고 실제 파일 경로를 확인하세요. 긴 작업의 진행 단계와 관련 기록은 [내 작업과 자동화](./05-tasks.md)도 참고하십시오.

## 5. 사용할 수 있는 기능 확인하기

문서 작성, 코드 수정, PDF·Excel 분석, 발표자료 제작, 검색과 외부 서비스 연동 등은 설치된 스킬·도구·Connection에 따라 제공됩니다. 스킬 이름을 몰라도 자연어로 요청할 수 있습니다. 입력창의 `/` 목록은 현재 프로젝트에서 노출되는 명령을 확인하는 방법입니다.

메일·캘린더 등 외부 서비스에는 별도 연결이 필요할 수 있습니다. 비밀번호나 API 키는 채팅에 쓰지 말고 AI에게 안전 입력을 요청하세요.

## 6. 큰 작업은 지원 AI와 나누기

서로의 결과 없이 조사할 수 있는 부분은 지원 AI에게 나누고, 앞 단계 결과가 필요한 일은 순서대로 진행할 수 있습니다. 주 담당 AI가 근거 확인과 통합을 책임집니다. 작은 작업에는 지원 AI를 만들 필요가 없습니다.

> 최신 기능 조사와 종료 기능 조사를 지원 AI에게 나눠 맡겨줘. 결과를 확인한 다음 가이드를 수정하고 링크를 검증해줘. 배포는 하지 마.

자세한 방법은 [지원 AI와 함께 일하기](./10-support-ai.md)를 참고하십시오.
