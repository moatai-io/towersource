# 설정·권한·보안

Tower는 여러 사람이 함께 쓰는 서버입니다. 그래서 설정, 권한, 보안의 기본 개념을 알고 있으면 안전하게 사용할 수 있습니다.

---

## 설정에서 바꿀 수 있는 것

설정 화면에서는 보통 다음을 확인하거나 바꿉니다.

| 항목 | 설명 |
|---|---|
| 테마 | 화면 색상과 보기 방식 |
| 언어 | UI 표시 언어 |
| 모델 | AI 응답에 사용할 모델 |
| 계정 | 로그인, 프로필, 알림 |
| 연동 | Google Workspace 같은 외부 연결 |
| 스킬 | 사용할 수 있는 AI 전용 작업법 |
| 관리자 설정 | 사용자, 모델, 권한, 시스템 상태 관리 |

사용자 권한에 따라 보이는 메뉴가 다를 수 있습니다.

---

## 모델 선택

모델은 AI의 엔진입니다. 빠른 모델, 강한 모델, 비용이 다른 모델이 있을 수 있습니다.

| 상황 | 추천 |
|---|---|
| 짧은 질문, 번역, 간단 요약 | 빠른 모델 |
| 코드 수정, 복잡한 분석 | 강한 모델 |
| PDF/Excel/슬라이드처럼 검증이 중요한 작업 | 강한 모델 또는 전용 스킬 |

모델 이름을 몰라도 괜찮습니다. 중요한 작업이면 “정확도 우선으로 진행해줘”라고 말하면 됩니다.

---

## 권한의 기본

Tower에서는 역할에 따라 볼 수 있는 범위가 다릅니다.

| 역할 | 대략적인 의미 |
|---|---|
| Admin/Operator | 서버와 여러 프로젝트를 관리할 수 있음 |
| Member | 자신이 속한 프로젝트에서 작업 가능 |
| Viewer/Guest | 제한된 읽기 중심 접근 |

프로젝트 파일, 게시물, 세션, 채널은 권한의 영향을 받을 수 있습니다.

---

## 파일 보안

다음 원칙을 기억하세요.

- 비밀번호, API 키, 토큰은 채팅에 붙여넣지 않습니다.
- `.env` 같은 파일 내용은 출력하지 않습니다.
- AI에게 “키가 있는지만 확인해줘”라고 할 수는 있지만 값은 보여주면 안 됩니다.
- 고객 자료는 올바른 프로젝트 안에 둡니다.
- 외부 공유 링크를 만들기 전에 공유 범위를 확인합니다.

---

## 외부 연동

Tower는 일부 외부 서비스와 연결할 수 있습니다. 예를 들어 Google Workspace 작업은 전용 경로를 사용합니다.

가능한 예:

- Gmail 확인 또는 초안 작성
- Calendar 일정 확인
- Drive/Docs/Sheets 자료 활용
- YouTube 대본 가져오기
- Naver 검색

다만 외부 서비스는 계정과 권한이 얽히므로, AI가 임의로 우회 연결을 시도하지 않습니다. 필요한 통합이 없으면 운영자에게 추가를 요청해야 합니다.

---

## 게시와 공개 범위

HTML 페이지나 대시보드를 게시할 때 공개 범위를 선택합니다.

| 공개 범위 | 의미 |
|---|---|
| private | 외부 URL 없음 |
| auth-required | Tower 로그인 필요 |
| unlisted | 주소를 아는 사람만 접근 가능, 기본 추천 |
| public | 공개 URL, 검색 노출 가능성 있음 |

일반 공유는 **unlisted**가 기본입니다. “공개로”, “SEO 필요”, “짧은 공개 URL”처럼 명시할 때만 public을 고려합니다.

---

## 관리자 기능

관리자는 다음 일을 할 수 있습니다.

- 사용자와 그룹 관리
- 프로젝트 접근 권한 관리
- 모델과 기본 설정 관리
- 자체 호스팅 서버 상태 점검
- 배포와 운영 로그 확인
- 스킬 배포와 검증

운영 작업은 일반 문서 수정과 다르게 영향 범위가 큽니다. 배포, 재시작, 자체 호스팅 서버 변경은 명시 요청과 검증 절차가 필요합니다.

---

## Git과 커밋 안전 규칙

개발 프로젝트에서 AI가 코드를 수정할 수 있지만, 커밋은 조심합니다.

- 사용자가 요청할 때만 커밋합니다.
- `git add -A`처럼 모든 변경을 한 번에 담지 않습니다.
- 현재 세션이 수정한 파일만 stage합니다.
- 다른 사용자의 변경이 섞여 있으면 분리합니다.
- 배포는 커밋의 자동 후속 작업이 아닙니다. 별도 요청이 필요합니다.

이 규칙은 공유 서버에서 다른 사람의 작업을 보호하기 위한 것입니다.

## 초보자용 안전 체크

무언가 공유하거나 바꾸기 전에 아래 질문을 해보세요.

1. 이 파일을 다른 사람이 봐도 되는가?
2. 이 링크는 로그인 없이 열리는가?
3. 이 변경이 다른 사용자나 자체 호스팅 서버에 영향을 주는가?
4. 되돌릴 수 있는가?
5. 결정 이유를 나중에 이해할 수 있게 남겼는가?

애매하면 AI에게 “영향 범위와 리스크를 먼저 알려줘”라고 요청하세요.
