# 시각화와 산출물

Tower는 AI 답변을 글로만 보여주지 않습니다. 차트, 표, 다이어그램, PDF, HTML, DOCX, 슬라이드 같은 **눈에 보이는 결과물**로 만들 수 있습니다.

---

## 채팅 안에서 바로 보이는 시각화

AI에게 “차트로 보여줘”, “흐름도로 그려줘”, “비교표로 정리해줘”라고 요청하면 채팅 안에 시각화가 렌더링될 수 있습니다.

| 형태 | 쓰는 상황 |
|---|---|
| Chart | 매출, 방문자, 비용 같은 숫자 비교 |
| Mermaid | 프로세스, 시스템 구조, 의사결정 흐름 |
| Data table | 검색·정렬 가능한 표 |
| Timeline | 일정, 히스토리, 로드맵 |
| Kanban | 할 일 상태를 간단히 보여줄 때 |
| Map | 장소와 위치를 보여줄 때 |
| Diff | 코드나 문서 변경 전후 비교 |

차트는 목적에 맞게 고르는 것이 중요합니다.

- 항목 비교는 bar 또는 table이 가장 명확합니다.
- 시간 흐름은 line 또는 area가 좋습니다.
- 상태 구성은 stacked bar가 좋습니다.
- pie는 전체 구성비가 핵심이고 항목이 3–5개일 때만 권장합니다.
- 색은 기본적으로 Tower의 차분한 teal/slate 톤을 쓰고, 빨강/노랑/초록은 위험·주의·성공 같은 의미가 있을 때만 씁니다.

복잡한 설명은 먼저 시각화로 보면 훨씬 빨리 이해됩니다.

---

## 파일로 남기는 산출물

채팅 안 시각화와 별개로, 공유 가능한 파일을 만들 수 있습니다.

| 산출물 | 언제 쓰나요? |
|---|---|
| Markdown | 내부 문서, 인계, 회의 정리 |
| PDF | 읽기 전용 보고서, 제출 문서 |
| DOCX | Word/Google Docs로 이어서 편집할 문서 |
| Excel | 분석 결과, 피벗, 비교표 |
| HTML | 대시보드, 랜딩페이지, 인터랙티브 보고서 |
| PPTX/슬라이드 | 발표자료, 제안서 |
| PNG/SVG | 인포그래픽, 삽화, 썸네일 |

AI에게 원하는 형식을 말하면 더 정확합니다.

예:

> 고객에게 보낼 최종본은 PDF로, 내부 수정용 원본은 Markdown으로 같이 남겨줘.

## PDF를 만들 때

PDF는 보이는 결과가 중요합니다. Tower는 HTML을 PDF로 내보내고, 렌더링된 페이지를 확인할 수 있습니다.

요청 예시:

> 이 보고서를 A4 PDF로 만들어줘. 표가 잘리지 않게 확인하고, 첫 페이지를 검증해줘.

PDF 작업에서 AI가 확인하는 것:

- 페이지가 잘리지 않는지
- 한글 폰트가 깨지지 않는지
- 표와 이미지가 넘치지 않는지
- 제목과 본문 간격이 자연스러운지

---

## HTML과 게시(Publish)

HTML은 웹페이지, 대시보드, 계산기, 인터랙티브 보고서를 만들 때 좋습니다. 문서보다 탐색하기 쉽고, 차트·표·필터·카드형 요약을 한 화면에 담을 수 있습니다.

공유하려면 Tower의 게시 기능을 씁니다.

- `index.html`이 있는 폴더를 준비합니다.
- 게시하면 외부 URL이 만들어집니다.
- 기본은 **unlisted**라서 주소를 아는 사람만 접근합니다.
- 공개 검색 노출이 필요할 때만 public을 씁니다.

요청 예시:

> 이 분석 결과를 고객이 볼 수 있는 HTML 리포트로 만들고, 게시 가능한 링크로 공유해줘.

> Excel 요약을 인터랙티브 대시보드 HTML로 만들고, 필터와 핵심 지표 카드를 넣어줘.

AI는 게시가 성공한 URL만 알려줘야 합니다. 추측으로 URL을 만들지 않습니다.

## PPT와 슬라이드

Tower는 여러 방식의 슬라이드 작업을 할 수 있습니다.

| 방식 | 특징 |
|---|---|
| HTML 슬라이드 | 디자인 자유도가 높고 PDF로 뽑기 좋음 |
| PPTX 템플릿 | 회사 양식에 맞춘 편집 가능한 PPT |
| 이미지 슬라이드 | 포스터/캠페인처럼 시각 임팩트가 중요할 때 |
| PDF → PPTX | 기존 PDF 발표자료를 편집 가능하게 바꿀 때 |

요청할 때 “편집 가능한 PPTX가 필요한지”, “PDF로 보기만 하면 되는지”를 말하면 좋습니다.

## Excel과 데이터 산출물

Excel/CSV 파일은 단순히 표로 읽는 것보다 구조를 파악하는 것이 중요합니다.

AI가 할 수 있는 일:

- 시트와 컬럼 구조 파악
- 병합 셀, 수식, 굵은 행, 총계 행 확인
- 기간별 비교
- 피벗/요약표 생성
- 이상치와 리스크 정리

요청 예시:

> 이 엑셀의 비즈니스 로직을 먼저 설명하고, 매출 변화가 큰 항목을 별도 Excel로 만들어줘.

## 좋은 산출물 요청법

다음 네 가지를 같이 말하면 결과가 좋아집니다.

1. **대상** — 누가 볼 것인가?
2. **형식** — PDF, HTML, DOCX, Excel, PPTX 중 무엇인가?
3. **톤** — 임원용, 고객용, 내부 공유용, 기술 문서용
4. **검증 기준** — 잘림 없음, 숫자 근거 포함, 추정 표시 등

예:

> 비개발 임원용 5페이지 PDF로 만들어줘. 첫 페이지는 결론, 중간은 근거, 마지막은 다음 액션으로. 표가 잘리지 않는지 검증해줘.
