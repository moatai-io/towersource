# 세션 — 요청과 후속 작업

세션은 AI와 대화하며 분석·작성·수정·검증을 이어가는 작업 기록입니다. 프로젝트의 지침과 파일을 사용하지만, 다른 세션의 모든 대화를 자동으로 기억하는 것은 아닙니다.

## 세션 만들고 찾기

업무에 맞는 AI 팀원이나 프로젝트를 선택하고 새 세션을 엽니다. 주제별로 “월간 매출 원인 분석”, “도움말 개편”처럼 구체적인 이름을 붙이면 다시 찾기 쉽습니다. 세션 제목 변경을 AI에게 요청할 수도 있습니다.

이전 대화가 필요하면 “지난번 자동화 설정을 논의한 세션을 찾아줘”라고 요청하세요. 검색된 요약은 단서이며, 중요한 결정은 실제 대화나 정본 문서로 확인해야 합니다.

세션의 공개 범위는 소유·공유·프로젝트와 대상 독자에 따른 접근 규칙으로 결정됩니다. 세션 링크 자체는 접근 권한을 주지 않습니다.

## 메시지와 자료 보내기

- 보통 **Enter**로 보내고 **Shift+Enter**로 줄을 바꿉니다. 한글 조합 중 입력이나 기기 설정에 따라 동작이 달라질 수 있습니다.
- 파일·이미지를 첨부하거나 프로젝트 파일 경로를 알려줍니다.
- `/` 명령 목록에서 현재 프로젝트가 제공하는 스킬을 확인할 수 있습니다.
- 마이크 기능이 제공되면 음성으로 초안을 입력하고 전송 전 내용을 확인합니다. 마이크 권한과 서버의 음성 서비스 설정이 필요합니다.

## 실행 중 요청 바꾸기

작업 중에도 추가 메시지를 보낼 수 있습니다. 전달 시점은 엔진과 현재 실행 상태에 따라 다릅니다.

- Pi 실행에서는 진행 중 지시를 전달하는 steering을 지원합니다. 입력창의 전달 대기·전달 상태를 확인하세요.
- 다른 실행 경로에서는 메시지가 다음 처리 순서를 기다릴 수 있습니다.
- 이미 실행한 명령이나 외부 변경은 새 지시나 Stop으로 되돌아가지 않습니다.

범위를 즉시 줄여야 한다면 “파일 수정은 멈추고 지금까지 확인한 근거만 정리해줘”처럼 구체적으로 말합니다. Stop 후에도 완료된 변경과 남은 실행이 있는지 확인하십시오.

## 질문·승인·진행 단계

AI는 중요한 선택을 묻는 질문 카드를 표시할 수 있습니다. 제시된 선택지나 다른 답으로 의도를 알려주세요. 외부 전송·배포·삭제 등의 승인은 구체적인 대상과 효과를 확인하고 판단합니다.

긴 작업에서는 **진행 단계** 카드가 AI의 실행 상태를 보여줍니다. 이 카드는 사용자의 개인 **내 할 일** 목록과 다릅니다. 단계 완료 표시만으로 결과의 정확성이 검증된 것은 아니므로 산출물과 검증 결과를 함께 확인합니다.

## 지원 AI 세션

주 담당 AI가 상당한 독립 작업을 지원 AI에게 위임할 수 있습니다. 지원 AI는 별도 Agent Session에 맥락과 실행 기록을 유지합니다. 사람 대화 목록과 지원 AI 목록은 구분되며, 사람이 지원 AI 세션에 참여해도 일반 Chat으로 자동 변경되지는 않습니다.

주 담당 AI는 지원 AI 보고를 받아 근거를 검증하고 결과를 합칩니다. 자세한 위임·재사용·중단 방법은 [지원 AI와 함께 일하기](./10-support-ai.md)를 참고하세요.

## 결과물과 후속 작업

파일을 만들었다면 경로와 Viewer를 확인합니다. “이 파일의 두 번째 절만 고쳐줘”처럼 대상을 지정하면 불필요한 재작성과 중복 파일을 줄일 수 있습니다.

같은 프로젝트의 세션과 지원 AI는 같은 파일을 사용할 수 있습니다. 동시에 수정할 때는 담당 파일과 수정 범위를 나누고 다른 작업자의 변경을 보존해야 합니다.

다음 세션으로 넘길 때는 목표, 완료된 결과, 파일 경로, 검증한 사항과 남은 일을 요약해 달라고 요청하세요. 별도 사이드바 대화를 만들려면 그 의도도 명시합니다.

## 좋은 요청 예시

> 한국어와 영어 도움말을 현재 코드와 대조해줘. 조사 결과를 확인한 뒤 문서를 수정하고 상대 링크를 검사해줘. 다른 작업자의 변경을 보존하고 배포와 커밋은 하지 마.

완료 보고에서는 **수정한 것, 실행한 검사, 미검증 사항**을 구분해서 확인합니다.
