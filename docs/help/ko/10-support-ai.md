# 지원 AI와 함께 일하기

지원 AI(서브에이전트)는 주 담당 AI가 상당한 전문 업무를 나눠 맡기는 동료입니다. 역할과 작업 맥락을 가진 지속 Agent Session에서 일하고, 보고를 받은 주 담당 AI가 근거를 확인해 결과를 통합합니다. 지원 AI를 만들었다고 프로젝트나 도구 권한이 넓어지지는 않습니다.

## 언제 나누면 좋을까요?

| 상황 | 진행 방법 |
|---|---|
| 같은 자료로 서로 다른 관점에서 독립 조사 | 입력과 출력이 확정되면 병렬 조사 |
| 조사 결과에 따라 구현 방향이 달라짐 | 조사 수용 후 결정·구현·검증 순서로 진행 |
| 작은 수정이나 짧은 확인 | 주 담당 AI가 직접 처리 |
| 같은 파일을 함께 수정해야 함 | 담당 범위와 선행 결과를 먼저 정하고 조율 |

역할이나 파일이 다르다는 이유만으로 독립 작업은 아닙니다. 앞 결과 없이도 각자 유효한 기여를 할 수 있는지 확인하세요. 조사 중 기준 자료가 바뀌면 입력 버전을 확인하고 조율해야 합니다.

## 요청하기

주 담당 AI에게 자연어로 요청합니다. `/agent` 명령이 제공되는 환경에서는 그 경로로 요청할 수도 있습니다. 모든 설치에서 지원 AI 관리 패널이 노출된다고 가정하지 마세요.

> 한국어·영어 가이드를 최신화해줘. 지원 AI 한 명은 현재 기능을, 다른 한 명은 종료·변경된 기능을 읽기 전용으로 조사하게 해줘. 근거를 확인한 뒤 네가 문서를 수정하고 링크를 검증해줘. 배포와 외부 공유는 하지 마.

주 담당 AI는 자식이 부모 대화를 본다고 가정하지 않고 다음을 전달해야 합니다.

- 전체 목표·로드맵·현재 단계·마일스톤과 완료 증거
- 필요한 전문성·판단 책임·실패 신호
- 정본 자료·기존 코드와 검증 경로·현재 가정
- 입력·출력·선행 결과·수정 소유권·통합 위치
- 담당 범위·금지 행동·제약과 막혔을 때 보고할 조건

작은 미션이라도 필요한 맥락은 충분히 전달합니다. 기존 팀의 문서·코드·검증 경로를 우선 확장하며, 관리용 파일이나 중복 보고서를 불필요하게 늘리지 않습니다.

## 진행 보기와 다시 맡기기

지원 AI는 미션이 끝난 뒤에도 세션과 맥락을 유지합니다. 목록·상태·최근 실행·현재 집중 항목을 주 담당 AI에게 확인해 달라고 할 수 있습니다. 기존 판단과 자료가 이어지는 일은 같은 지원 AI에게 후속 요청을 보내면 됩니다. 일회성 업무도 지속 Agent Session을 사용하므로 매번 새 동료를 만들 필요는 없습니다.

접근 권한이 있다면 연결된 Agent Session에서 대화와 실행 기록을 확인할 수 있습니다. 일반 Chats와 Agent Sessions는 구분됩니다. 사람이 지원 AI 세션에 참여해도 Agent 정체성이나 기존 제어 관계가 자동으로 없어지지는 않습니다.

지원 AI의 보고는 요청한 진행자에게 돌아가며 보통 진행자의 작업을 재개합니다. 생성 성공이나 메시지 전달 성공은 업무 완료나 검증 통과와 다릅니다. 별도 세션이라는 사실만으로 프로젝트 파일이나 OS가 격리되는 것도 아닙니다.

## 중단·일시정지·재개·보관

| 동작 | 의미와 주의점 |
|---|---|
| 현재 실행 중단 | 대상을 명확히 지정하고 실제 실행 상태를 확인합니다. 가능한 경우 연결된 지원 AI 세션에서 Stop을 사용합니다. |
| 일시정지 | 재개 전까지 후속 요청을 거절하는 상태로 바꿉니다. 진행 중인 실행을 즉시 취소하는 기능은 아닙니다. |
| 재개 | 일시정지된 동료가 다시 후속 업무를 받을 수 있게 합니다. |
| 보관 | 지원 AI 등록 항목을 보관하고 backing Session은 보존합니다. 진행 중 실행의 즉시 취소를 보장하지 않습니다. |

주 담당 세션의 Stop만으로 모든 지원 AI가 함께 멈춘다고 가정하지 마세요. 완료된 파일 수정과 외부 작업은 이 동작으로 되돌아가지 않습니다. 외부 전송·배포·삭제·비용이 드는 실행은 원래의 권한과 승인 조건을 그대로 따릅니다.

## 별도 대화 세션과의 차이

지원 AI는 역할·위임·보고를 중심으로 관리합니다. 사람이 독립적으로 이어갈 사이드바 대화가 필요하면 “별도 세션을 만들어 이어서 논의해줘”라고 명시하세요. 별도 세션과 지원 AI는 목적과 관리 방식이 다릅니다.

## 결과 확인

최종 보고에서 통합한 결과, 근거, 실행한 검사, 남은 불확실성을 확인하세요. 여러 지원 AI가 같은 결론을 냈다는 사실만으로 정답이 되는 것은 아닙니다. 원래 요청의 미완료 항목과 새로운 제안도 구분해야 합니다.
