# 단축키와 좋은 요청법

단축키는 반복 행동을 빠르게 해주지만, 결과 품질에는 구체적인 요청이 더 큰 영향을 줍니다.

## 확인된 단축키

### 메시지 입력

| 행동 | 단축키 |
|---|---|
| 메시지 보내기 | `Enter` |
| 줄바꿈 | `Shift+Enter` |
| 입력 제안 적용 | `Tab` |
| 제안 또는 임시 입력 상태 닫기 | `Esc` |

한글·일본어·중국어 입력기가 글자를 조합 중일 때 조합 확정 동작이 별도 메시지 전송으로 처리되지 않도록 Tower가 구분합니다.

### Viewer Pane

| 행동 | 단축키 |
|---|---|
| 편집 중인 파일 저장 | `Ctrl+S` 또는 `Cmd+S` |
| 현재 파일 탭 닫기 | `Ctrl+W` 또는 `Cmd+W` |
| 다음 파일 탭 | `Ctrl+Tab` |
| 이전 파일 탭 | `Ctrl+Shift+Tab` |
| 파일 탭 탐색 기록 이동 | `Alt+Left` 또는 `Alt+Right` |

환경에 따라 브라우저나 운영체제 단축키가 먼저 처리될 수 있습니다.

### Mermaid preview

Mermaid preview에 focus가 있거나 확대된 상태에서 사용할 수 있습니다.

| 행동 | 단축키 |
|---|---|
| 화면에 맞추기 | `0` |
| 100% 보기 | `1` |
| 확대·축소 | `+` 또는 `-` |
| 이동 | 방향키 또는 drag |
| 확대 화면 닫기 | `Esc` |

## 좋은 요청 작성하기

결과를 실제로 바꾸는 정보를 포함합니다.

### 1. 원하는 결과를 말합니다

다음 요청보다:

> 이거 검토해줘.

다음처럼 말하는 것이 좋습니다.

> 이 제안서를 검토하고 승인 가능성을 가장 크게 낮추는 문제 3개를 찾아줘.

### 2. 독자를 말합니다

> 기술 지식이 없는 임원이 5분 안에 투자 여부를 결정할 수 있게 작성해줘.

독자에 따라 용어, 근거, 상세 수준과 행동 요청이 달라집니다.

### 3. 산출물 형식을 정합니다

> 독립적으로 읽을 수 있는 Markdown 보고서를 `final/`에 저장하고 Viewer Pane에서 열어줘.

PDF, DOCX, Excel, 정적 사이트 또는 편집 가능한 원본이 필요하면 함께 말합니다.

### 4. 제약을 명시합니다

유용한 제약에는 다음이 있습니다.

- 반드시 사용하거나 사용하면 안 되는 출처
- 길이와 페이지 수
- 언어
- 개인정보와 권한 경계
- 외부 작업 허용 여부
- 불확실한 내용을 표시하는 방법
- 파일을 실제 수정할지 권고만 할지

### 5. 완료 기준을 정합니다

> 모든 권고가 대상 파일, 예상 영향과 검증 방법을 포함하면 완료야.

확인 가능한 완료 기준은 막연한 완료 보고를 줄여줍니다.

## 같은 세션을 이어갈 때

목표, 원본 자료와 결정이 계속 연결되어 있다면 같은 세션을 사용합니다. 주제나 독자가 크게 바뀌거나 별도의 업무 흐름이 독립적인 이력을 가져야 한다면 새 세션을 만듭니다.

## 첨부 파일과 프로젝트 파일

업로드한 첨부 파일은 사용자가 개인 공간 또는 프로젝트에 저장해 달라고 명시하지 않으면 임시 파일입니다. 분석 요청이 곧 영구 저장 동의는 아닙니다.

기존 프로젝트 파일을 수정하려면 경로를 알려주거나 파일을 연 뒤 요청하는 것이 좋습니다. AI가 만든 산출물은 최종 파일 경로를 함께 보고하도록 요청할 수 있습니다.

## 보호되는 작업

검토·진단·계획 요청은 배포, 삭제, 구매, 외부 메시지 전송과 같은 보호 작업을 자동으로 허용하지 않습니다.

외부 작업이 필요하면 대상과 예상 효과를 명확히 말합니다. Tower는 실제 실행 직전에 다시 확인할 수 있습니다.

## 요청 예시

> 현재 영문 설치 가이드를 실제 package script와 `.env.example`에 대조해줘. 공개 문서만 수정하고 Runtime code와 배포 script는 바꾸지 마. 다른 세션의 로컬 변경을 보존하고 모든 상대 링크를 검사한 뒤 변경 파일과 남은 불확실성을 보고해줘.

## 추가 탐색 단축키

설정에서 단축키를 바꿀 수 있으며, 다음은 기본값입니다. 입력창·질문 카드의 활성 상태와 브라우저·OS에 따라 적용 여부가 달라집니다.

| 행동 | 기본 단축키 |
|---|---|
| 음성 입력 시작·종료 | `Alt+V` |
| 이전·다음 세션 | `Alt+Shift+↑` / `Alt+Shift+↓` |
| 이전·다음 사용자 메시지 | `Alt+↑` / `Alt+↓` |
| 질문 카드 선택지 선택 | `1`–`9` (카드가 활성화된 경우) |
