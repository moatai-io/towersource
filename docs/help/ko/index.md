# Tower 한눈에 보기

Tower는 팀이 AI 팀원과 함께 대화하고, 파일을 만들고, 도구를 실행하고, 반복 업무를 운영하는 셀프호스트형 업무 공간입니다.

> **담당 AI 팀원 찾기 → 세션에서 요청 → 결과와 검증 확인 → 필요한 곳에 저장·전달**

## 핵심 개념

| 개념 | 의미 |
|---|---|
| AI 팀원 | 역할과 책임을 갖고 작업공간을 맡는 Primary Agent |
| 프로젝트 | 파일·세션·접근 권한·연결의 기술적 경계 |
| 세션 | 요청과 도구 실행, 판단과 후속 작업의 기록 |
| 지원 AI | 주 담당 AI가 전문 업무를 위임하고 결과를 통합하는 동료 |
| 파일·Viewer | 보관한 자료와 산출물을 찾고 확인하는 경로 |
| 진행 단계 | 현재 AI 실행의 단계 표시. 개인 내 할 일과는 별개 |
| 내 작업 | 관련 업무 기록과 대화, 승인·후속 판단을 확인하는 곳 |
| 자동화 | 정해진 시점이나 주기로 실행하는 업무 |
| 스킬 | 특정 업무를 수행하는 재사용 가능한 작업법 |
| Connection | 허용된 범위에서 외부 서비스를 쓰는 연결 |

## 제공 조건과 안전

기능은 설치 버전·역할·프로젝트 정책·서비스 연결에 따라 달라집니다. 음성 기능처럼 서버가 별도로 켜야 하는 실험 기능도 있습니다. 코드나 문서가 존재한다고 모든 서버에서 사용할 수 있는 것은 아닙니다.

- AI 팀원 목록에 보이는 것과 실행·파일 접근 권한은 구분됩니다.
- 같은 프로젝트의 세션과 지원 AI는 같은 파일을 사용할 수 있습니다.
- 개인 자료·메모와 공유 프로젝트 파일의 접근 경계는 다릅니다.
- 대화 첨부를 읽는 것과 원본을 영구 저장하는 것은 별도 요청입니다.
- 다른 프로젝트로 전달하거나 게시할 때는 대상과 범위를 확인합니다.
- 비밀번호·API 키는 채팅이나 문서에 쓰지 말고 안전 입력 흐름을 사용합니다.
