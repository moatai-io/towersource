# Tower 한눈에 보기

Tower는 팀이 AI 팀원과 함께 대화하고, 파일을 만들고, 실제 도구를 실행하고, 반복 작업을 운영하는 셀프호스트형 업무 공간입니다.

처음에는 다음 흐름만 기억하면 됩니다.

> **AI 팀원 또는 프로젝트를 고르고 → 세션에서 일을 맡기고 → 파일과 진행 상황을 확인하고 → 필요한 결과만 공유합니다.**

## 핵심 개념

| 개념 | 의미 | 주로 하는 일 |
|---|---|---|
| **AI 팀원** | 특정 역할과 작업공간을 책임지는 Primary Agent | 담당 업무를 이어서 수행 |
| **프로젝트** | 파일·세션·멤버·권한·Credential의 기술적 경계 | 팀 또는 AI 팀원의 업무공간 구성 |
| **세션** | 프로젝트 안에서 이어지는 AI 대화와 실행 기록 | 요청, 수정, 후속 작업 |
| **파일** | 다시 열고 공유할 수 있는 자료와 산출물 | 문서, 코드, PDF, Excel, HTML 관리 |
| **내 작업** | 진행 중인 업무, 승인, 실행 기록을 보는 곳 | 상태 확인과 후속 조치 |
| **자동화** | 정해진 시점이나 주기로 실행되는 AI 작업 | 브리핑, 점검, 반복 보고 |
| **스킬** | 특정 일을 안정적으로 수행하는 전용 작업법 | 문서·검색·회의·데이터 작업 |
| **Connection** | AI 팀원이 외부 서비스를 사용할 수 있게 하는 승인된 계정 연결 | Google Workspace, 검색·콘텐츠 API 등 |

## 가장 흔한 사용 흐름

### 문서나 분석 결과 만들기

1. 담당 AI 팀원 또는 프로젝트를 선택합니다.
2. 새 세션을 열거나 기존 세션을 이어갑니다.
3. 대상 독자, 원하는 형식, 반드시 지킬 조건을 함께 요청합니다.
4. AI가 만든 파일을 Viewer Pane 또는 파일 화면에서 확인합니다.
5. 필요한 부분을 같은 세션에서 수정합니다.

### 파일 분석하기

1. 파일을 메시지에 첨부하거나 프로젝트 파일로 저장합니다.
2. 원하는 판단 기준과 결과 형식을 말합니다.
3. PDF·Excel·CAD처럼 전용 분석이 필요한 파일은 Tower가 적절한 도구를 사용합니다.
4. 다시 사용할 결과는 프로젝트 파일로 남깁니다.

### 반복 작업 등록하기

1. “매주 월요일 오전 9시에 지난주 업무를 요약해줘”처럼 요청합니다.
2. AI와 시간, 대상 프로젝트, 결과를 남길 곳을 확인합니다.
3. 최종 내용을 승인하면 Automation으로 등록됩니다.

### 외부 서비스를 사용하기

1. 작업에 필요한 스킬 또는 도구를 선택합니다.
2. 계정 연결이 필요하면 Tower의 안전 입력 흐름으로 Connection을 등록합니다.
3. Credential 값은 대화나 프로젝트 파일에 적지 않습니다.
4. 연결 권한과 실제 실행 시 주입 여부는 별도로 관리됩니다.

## 권한과 안전

- 프로젝트 파일과 세션은 프로젝트 멤버십과 역할에 따라 접근합니다.
- 개인 파일과 개인 메모는 프로젝트 파일과 다른 경계에 저장됩니다.
- 삭제, 배포, 외부 전송처럼 영향이 큰 작업은 별도 확인이 필요할 수 있습니다.
- AI 팀원과 Helper Agent는 자신에게 허용된 프로젝트·도구·Credential 범위 안에서만 작업합니다.
- 같은 서버에 파일이 존재한다고 해서 모든 사용자가 접근할 수 있는 것은 아닙니다.
