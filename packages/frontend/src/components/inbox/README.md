# Inbox / 답변 대기

`InboxPanel.tsx`는 모바일·데스크톱의 답변 대기 및 WorkHub 결과 목록을 담당합니다.

## 세션 보관 계약

- 기본 결과 목록에서는 `SessionMeta.archived`가 참인 세션을 제외합니다. 보관함에서 열어 store에 다시 들어온 세션도 미확인·실행 중·최근 읽음 상태와 관계없이 제외합니다.
- `보관함으로 이동`은 목록에서만 숨기는 dismiss와 다릅니다. 공유 참여자의 기본 목록에서도 제외됨을 확인받고 `POST /api/sessions/:id/archive`를 호출합니다.
- 성공한 요청만 store와 대기 메시지 queue에서 제거합니다. 보관 snapshot 갱신 이벤트와 보관함 열기 알림을 제공합니다.
- HTTP 오류와 네트워크 오류는 사용자에게 알리고 목록을 유지합니다. 확인 취소 시 요청하지 않습니다.
- 일반 사이드바의 명시적 `보관된 세션 포함` 필터는 별도 정책이며 유지합니다.

정책: [세션 보관 결정](../../../../../docs/decisions/2026-09-14-session-archive-not-trash.md)

검증: `InboxPanel.archive.test.tsx`에서 모바일/데스크톱의 보관 열람 제외, 성공, 취소, HTTP·네트워크 실패를 검사합니다. 컴포넌트 테스트는 실제 모바일 브라우저나 운영 배포 검증을 대신하지 않습니다.
