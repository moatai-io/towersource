# Notifications module decisions

- 알림 타입은 기존 `mention`, `task_done` 같은 legacy 값을 유지 수신하되, 저장/정책 판단 시 `message.mention`, `task.completed` 같은 dot notation으로 정규화한다.
- 프로젝트 mute가 이벤트별 설정보다 우선한다. 사용자가 특정 프로젝트를 조용하게 만들면 해당 프로젝트 이벤트는 저장/토스트 대상에서 제외된다.
- `web_push`는 실제 발송까지 연결되어 있지만 명시적 opt-in 경험으로 다룬다. 전역 기본값은 꺼두고, 사용자가 설정에서 켜며 브라우저 권한/구독을 만든 뒤에만 실제 OS 알림을 받을 수 있다. 기본 추천 대상은 멘션, 승인 필요, 실패/오류, 내가 시작한 긴 작업 완료로 제한한다.
- 알림 정책은 `notification-hub` 앞단에서 해석한다. 호출부가 프로젝트/세션/우선순위를 넘기면 hub가 설정을 반영하고, 호출부는 채널 세부사항을 몰라도 된다.
